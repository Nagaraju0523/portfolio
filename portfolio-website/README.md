# Nagaraju Gajji - Developer Portfolio & Freelance Platform

A high-performance freelance developer portfolio engineered with **React 19**, **Vite**, and a **Glassmorphism Design System**.

## 🎨 Glassmorphism Design System

- **Background Atmosphere**: Rich colorful gradient (deep purple, blue, and teal) with soft blurred floating orbs (`filter: blur(95px - 120px)`) that slowly animate via organic CSS translations.
- **Glass Cards**: Semi-transparent white (`rgba(255, 255, 255, 0.1–0.2)`), `backdrop-filter: blur(16–24px)`, `1px` translucent white border (`rgba(255, 255, 255, 0.18)`), rounded corners (`16–24px`), and a soft layered shadow.
- **Frosted-Glass Depth**: Subtle inner specular highlight on the top/left edge (`inset 1px 1px 1px 0 rgba(255, 255, 255, 0.35)`).
- **Hover Micro-Interactions**: Gentle lift (`translateY(-6px)`), brighter white border (`rgba(255, 255, 255, 0.45)`), and slight dual purple/teal aura glow.
- **Typography & Accessibility**: Modern sans-serif hierarchy using **Poppins** for bold headings and **Inter** for clean body text, with pure white and light silver text complying with WCAG AA standards.
- **Motion & Physics**: Restrained 0.3s ease transitions and scroll-reveal keyframes with full support for `prefers-reduced-motion`.

## 🛠️ Tech Stack

- **Frontend**: React 19, JavaScript (ES6+), Vite 8
- **Icons**: Lucide React + custom SVGs
- **Typography**: Google Fonts (Poppins, Inter, JetBrains Mono)
- **Deployment**: Production build ready via `npm run build`

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run linter
npm run lint

# Build for production
npm run build
```
